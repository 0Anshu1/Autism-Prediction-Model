# Autism Prediction using Machine Learning

## Overview
This project aims to predict autism using machine learning techniques. The model is trained on relevant features and employs classification algorithms to determine the likelihood of autism.

## Features
- Data preprocessing and feature selection
- Machine learning model training and evaluation
- Predictions based on input features

## Requirements
```bash
Python 3.x
Jupyter Notebook
Required libraries (install using `pip install -r requirements.txt` if applicable)
1. Open the Jupyter Notebook.
2. Run the cells sequentially to preprocess data, train the model, and make predictions.
3. Modify the dataset or model parameters as needed.
